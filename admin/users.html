Users

Who has admin access. RLS enforces this — removing someone here revokes all write access immediately.

    Add admin access

    The person must already have a Supabase Auth account (created in the Supabase dashboard or via the invite flow). Paste their User UID from Authentication → Users.

    Invite a new Supabase user

    The Supabase dashboard → Authentication → Users → Invite user lets you send an invite email. Once they sign up, paste their UUID above to grant admin access.

    Open Supabase dashboard ↗

    Two-factor authentication

    Require a 6-digit code from an authenticator app on every login. Strongly recommended.

    Checking…

    Scan the QR code with Google Authenticator, Authy, or any TOTP app, then enter the 6-digit code to confirm.

    Can't scan?

    Two-factor authentication is active
    Every login requires your authenticator code after the password.
